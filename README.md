# SMK DevLabs | Mobile App Development Company

> **"We Build Mobile Apps That People Love"**

SMK DevLabs는 글로벌 사용자를 위한 빠르고 안정적이며 사용자 친화적인 모바일 애플리케이션을 개발하는 모바일 중심 소프트웨어 기업입니다.

---

## 📱 Featured Product (대표 제품)

### **TikiTalk**
- 쉽고 즐거운 대화를 위한 소셜 커뮤니케이션 플랫폼입니다. 사용자가 언제 어디서나 쉽게 연결하고 채팅하며 소중한 순간을 공유할 수 있도록 지원합니다.
- [Google Play에서 다운로드하기](https://play.google.com/store/apps/details?id=com.smk.tikitalk)

---

## ✨ Key Features (주요 강점)

- **Mobile-First Design**: 모든 제품은 최상의 스마트폰 사용자 경험(UX)을 최우선으로 설계되었습니다.
- **Fast Development**: 아이디어를 효율적이고 빠르게 실제 작동하는 모바일 앱으로 구현합니다.
- **Global Ready**: 다국어 지원 및 글로벌 사용자를 고려하여 확장성 있게 개발됩니다.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid, Responsive Design), Vanilla JavaScript (ES6+)
- **Features**: 
  - 다국어(한국어/영어) 토글 기능 (`localStorage` 및 시스템 언어 자동 감지 연동)
  - 반응형 다크 모드 UI
